# Borza Academy Learning Standard

## Required lesson anatomy

A review-ready lesson contains:

- measurable learning objectives;
- a clear explanation and financial intuition;
- a realistic numerical or decision example;
- a common beginner error;
- a step-by-step decision framework;
- a worked example;
- a short knowledge check with useful incorrect-answer feedback;
- an applied calculator, chart, or scenario exercise where relevant;
- a reflection prompt and journal handoff;
- a contextual next action;
- reliable sources for factual claims.

Duration estimates must reflect reading, calculation, exercise, and reflection time—not only the length of the summary.

## Evidence model

Mastery is supported by multiple evidence types:

1. Lesson completion shows exposure, not mastery.
2. Quiz answers show immediate understanding.
3. Review cards show delayed recall.
4. Calculator and chart work show application.
5. Simulator evidence shows precommitment, risk control, and rule adherence.
6. Journal reflection shows the learner can distinguish process from outcome.
7. Decision Lab, Scam Detector, and Life Simulator attempts show applied reasoning against versioned cases.
8. The Competence Passport aggregates multiple sources but never converts exposure into certification.

One multiple-choice answer or one profitable simulation cannot create mastery.

Practical evidence records content version, source type, source ID, process score, corrective feedback, and time. A client-supplied score is never authoritative: authenticated evidence is evaluated from canonical server content.

## Assessment principles

- Score reasoning and process separately from financial outcome.
- Give specific corrective feedback and name the concept to review.
- Accept well-reasoned no-trade and no-purchase decisions.
- State uncertainty and avoid guaranteed-pattern language.
- Use exact decimal calculations for monetary and risk quantities in runtime services.
- Preserve deterministic scenario and content versions so evidence is reproducible.

## Content quality gates

The Academy validator checks stable identifiers, order, prerequisites, locale coverage, source references, knowledge checks, glossary, review cards, exercises, and scenarios. Editorial review additionally checks natural language, age appropriateness, factual accuracy, accessibility, and responsible-finance boundaries.

## Accessibility

Learning must remain usable with keyboard navigation, semantic headings and landmarks, visible focus, high contrast, screen-reader labels, chart text summaries, reduced motion, touch-friendly controls, and clear validation/error states. A chart-only answer is incomplete without a textual equivalent.
